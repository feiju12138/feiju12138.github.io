【笔记】Java的面向对象

发表于 2020-01-22 更新于 2026-09-05 分类于 Java学习指北 阅读次数：
116180736737128580

前言

Java的面向对象（Object-Oriented Programming, OOP）学习笔记

类

定义类

  • 类名采用大驼峰
  • 一个.java文件可以定义多个类，但只能有一个由public修饰的类，文件名需要与public修饰的类的类名保持一致

通过类创建对象

  • 对象名采用小驼峰

类中定义属性

  • 属性名采用小驼峰

类中定义方法

  • 方法名采用小驼峰

方法的参数列表

可变长参数
  • 可变长参数得到的是一个数组
  • 可变长参数必须在形参列表最后定义

方法的重载

  • 同一个类中定义多个同名方法，方法名相同，参数列表不同

方法的返回值

类中定义构造方法

  • 构造方法名与类名同名
  • 构造方法没有返回值类型，也无需使用void关键字
  • 没有定义构造方法时，类中默认包含一个无参构造方法
  • 通过new关键字创建对象时，构造方法会被执行

this关键字

  • 通过this访问当前实例
  • this只能在方法中使用
  • 方法中访问实例属性和实例方法时可以省略this.

访问实例属性

调用实例方法

调用构造方法

  • 通过this()调用当前类的其他构造方法
  • this()只能用在构造方法中
  • this()必须位于构造方法的第一行

final关键字

修饰变量

  • 被final修饰的变量，值不能被修改

修饰类

  • 被final修饰的类不能被继承

修饰属性

  • 被final修饰的属性，值不能被修改

修饰方法

  • 被final修饰的方法不能被重写

static关键字

  • 通过类名直接访问

静态属性

静态方法

  • 静态方法中只能访问静态属性和静态方法

静态代码块

  • 静态代码块会在类加载时执行且仅执行一次

类创建对象时的执行顺序

继承

  • 通过extends继承父类
  • 子类只能继承一个父类
  • 子类继承父类后，子类实例可以访问父类属性和方法

方法的重写

  • 子类重写父类同名方法
  • @Override注解用于标注这是重写的方法

super关键字

  • 通过super访问父类实例
  • super只能在方法中使用

访问父类实例属性

访问父类实例方法

访问父类构造方法

  • 通过super()调用父类构造方法
  • super()只能用在构造方法中
  • super()必须位于子类构造方法的第一行

抽象类和抽象方法

定义抽象类

  • 通过abstract关键字修饰的类是抽象类

抽象类中定义抽象方法

  • 通过abstract关键字修饰的方法是抽象方法，抽象方法不需要定义方法体
  • 抽象类中定义的方法可以是抽象的也可以不是抽象的

子类继承抽象类

  • 子类通过extends继承抽象类
    • 子类只能继承一个父类
    • 子类继承抽象类时必须重写抽象类中的所有抽象方法
  • 如果不重写接口定义的所有抽象方法，则子类一定也是抽象类

接口

定义接口

  • 通过interface关键字定义接口

接口中定义抽象方法

  • 接口中定义的普通方法一定都是抽象的
  • 接口中定义抽象方法时可以省略public、abstract关键字

接口中抽象方法的默认实现

接口中定义常量属性

  • 接口中的属性一定都是常量
  • 接口中定义常量属性时可以省略public、static、final关键字

接口中定义静态方法

  • 接口中定义静态方法时可以省略public关键字

子类实现接口

  • 子类通过implements实现接口
    • 子类可以实现多个接口，多个接口名之间用,分隔
    • 子类实现接口时必须重写所有接口定义的所有抽象方法
  • 如果不重写接口定义的所有抽象方法，则子类一定是抽象类

父类引用指向子类对象

|—|—|—|—|—|
|public|公共权限|✓|✓|✓|✓|
|protected|保护权限|✓|✓|✓|×|
|无修饰符||✓|✓|×|×|
|private|私有权限|✓|×|×|×|

  • 类的权限修饰符只能是public和无修饰符

内部类访问外部类的属性和方法

  • 内部类没有同名属性或方法，可以直接调用
  • 内部类有同名属性或方法，需要通过类名访问
  • 外部类属性名、内部类属性名、方法内变量名重名时，需要显式指定访问的属性或变量

定义内部类

定义内部接口

通过匿名内部类为抽象类或接口创建对象

  • 创建对象时，通过匿名内部类，直接重写接口或抽象类的抽象方法

Lambda表达式

  • 有且只有一个抽象方法的接口使用匿名内部类时，可以将匿名内部类简写为Lambda表达式
  • 如果方法体只有一行，那么可以省略{}和return关键字
