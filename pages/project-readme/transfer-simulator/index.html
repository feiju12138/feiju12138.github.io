转账模拟器 TransferSimulator

朋友聚会，轻松记分。

转账模拟器是一款用于线下桌游聚会的 iOS 多人记分工具。由房主统一记录分数变化，其他成员在自己的设备上同步查看，方便大家专注于游戏。

应用仅记录模拟分数，不提供真实资金转账、支付或提现功能。

隐私政策

可以做什么

  • 多人房间：支持 2、3、4、5、6、8 人房间，成员通过附近设备连接申请加入，由房主批准。
  • 统一记分：房主选择转出座位和接收座位，输入数额后同步更新分数。支持负数和一位小数。
  • 灵活座位：按人数排列座位，支持换座，并可选择是否携带分数。
  • 虚拟成员：朋友没有安装应用时，房主可以添加虚拟成员，代为记录分数。
  • 成员管理：房主可以移除成员、处理重新加入申请，或让新成员替换离线成员。替换后保留对应座位的分数和记录。
  • 历史记录：查看每次分数调整的双方、数额和时间，为房间添加备注，管理本地历史。
  • 继续新局：房主可重置所有当前分数，同时保留房间中的历史交易记录。
  • 桌面小组件：查看当前房间自己的分数，点击小组件打开应用。
  • 个人资料：使用随机头像和英文昵称，也可以自定义昵称。

快速开始

  1. 所有参与者打开应用。房主选择“创建房间”，设置人数。
  2. 其他成员选择“加入房间”，找到附近房间后提交申请。
  3. 房主批准申请，安排座位；也可以添加虚拟成员。
  4. 房主开始记分，选择转出和接收座位，输入数额并确认。
  5. 在房间右上角打开交易记录；离开后可在主界面的历史记录中查看已保存的记录。

多人连接时，请允许应用访问本地网络，保持设备靠近，并建议连接同一 Wi-Fi。连接效果受设备、系统和网络环境影响。

常见问题

应用会真的转账吗？

不会。这里的“转账”仅表示两个座位之间的模拟分数变化，不连接银行卡或支付账户。

找不到房间怎么办？

请确认房主已创建房间，双方都允许了本地网络权限。保持应用在前台，尝试将设备连接至同一 Wi-Fi，然后重新进入房间搜索页面。你也可以在 iOS“设置”中检查应用的本地网络权限。

断开连接后能回到原来的座位吗？

普通离开后重新加入，默认保留原座位。如果座位已被调整或由其他成员替换，需要由房主手动安排。离线成员不能参与新的分数调整，需先恢复连接。

房间已经解散，但我仍看到旧房间怎么办？

如果你在断开连接时错过了解散通知，可以回到主界面，对保留的房间选择“强制退出”。强制退出后，再次加入需要房主处理；已保存的本地历史不会因此自动删除。

怎样取消已经选中的座位？

再次点击已选中的转出座位，会同时取消转出和接收座位；再次点击已选中的接收座位，只取消接收座位。

换人后，分数和记录属于谁？

分数和交易记录与房间中的座位关联。新成员替换旧成员时，会接替该座位的分数和记录。房主换座时，可以选择是否携带分数。

如何开始新一局，又保留之前的记录？

由房主使用重置当前房间所有计数器的功能。当前分数归零，既有交易记录继续保留，无需重新创建房间或安排成员。

如何备注或删除历史房间？

在历史记录列表中，向右滑动显示绿色备注按钮；向左滑动显示红色删除按钮。删除前会要求确认。删除本地历史不会解散其他设备上的房间，也不会删除其他成员的记录。

小组件的分数没有立即更新怎么办？

先打开应用确认房间连接和最新分数，再查看小组件。小组件的刷新时机由 iOS 调度，可能存在延迟。
