前言

MySQL（官方发音为/maɪ ˌɛskjuːˈɛl/“My S-Q-L”，但也经常被读作/maɪ ˈsiːkwəl/“My Sequel”）原本是一个开放源码的关系数据库管理系统，原开发者为瑞典的MySQL AB公司，该公司于2008年被昇阳微系统（Sun Microsystems）收购。2009年，甲骨文公司（Oracle）收购昇阳微系统公司，MySQL成为Oracle旗下产品。（维基百科）

数据类型

数值类型

数据类型 备注
TINYINT 8位有符号整型
SMALLINT 16位有符号整型
MEDIUMINT 24位有符号整型
INTEGER、INT 32位有符号整型
BIGINT 64位有符号整型
FLOAT 32位有符号近似浮点型
DOUBLE 64位有符号近似浮点型
DECIMAL(10,0)、NUMERIC(10,0) 有符号精确数值型，总有效数字最大65，默认值为10，小数位数最大30，默认值为0

字符串

数据类型 备注
CHAT(255) 定长字符串，数据长度不足会自动在末尾补空格，数据类型定义范围为[CHAT(0),CHAT(255)]
VARCHAR(65535) 可变长字符串，数据类型定义范围为[VARCHAR(0),VARCHAR(65535)]
TEXT 超大可变长字符串
BINARY(255) 定长二进制字符串，数据长度不足会自动在末尾补0x00，数据类型定义范围为[BINARY(0),BINARY(255)]
VARBINARY(65535) 可变长二进制字符串，数据类型定义范围为[VARBINARY(0),VARBINARY(65535)]
BLOB 超大可变长二进制字符串

日期类型

数据类型 备注
YEAR 格式为yyyy，范围为[‘1901’,’2155’]
DATE 格式为yyyy-MM-dd，范围为[‘1000-01-01’,’9999-12-31’]
DATETIME 格式为yyyy-MM-dd HH:mm:ss，范围为[‘1000-01-01 00:00:00.000000’,’9999-12-31 23:59:59.999999’]
TIMESTAMP 格式为yyyy-MM-dd HH:mm:ss，范围为[‘1970-01-01 00:00:00.000000’,’2038-01-19 03:14:07.999999’]

对约束的操作（Data Definition Language, DDL）

添加约束

  • 在建表时直接加约束到字段定义的后面

<constraint>：约束（同时指定多个约束时，用空格分隔）

NULL：可以为空，缺省值
NOT NULL：非空约束，定义这个字段不允许为空
PRIMARY KEY：主键约束，必须为非空，必须不重复

AUTO_INCREMENT：如果是数值型主键，可以定义逐渐自增
UNIQUE：唯一约束，定义这个列的值必须是唯一的、不能重复的，但可以为空
DEFAULT 默认值：默认约束，当没有为字段赋值时的默认值
ON UPDATE 值：没当执行修改操作时，字段的值会更新为指定值
AUTO_INCREMENT：自增
COMMENT ''：注释

  • 在建表时定义约束在所有字段定义的后面

<constraint>：约束（同时指定多个约束时，每行一种约束的定义）

PRIMARY(<field_name_1>)：定义主键约束，必须为非空，必须不重复
PRIMARY(<field_name_1>, <field_name_2>)：定义联合主键约束，每个主键字段的数值可以重复，但是多个联合主键的数值的并集不可以重复
UNIQUE(<field_name>)：定义唯一约束，定义这个列的值必须是唯一的、不能重复的，但可以为空
CHECK(<field_name><operator><value>)：定义完整性约束，为字段定义范围，仅8.x可以使用

修改或删除约束

<constraint>：修改后的约束（同时指定多个约束时，用空格分隔），如果修改后不添加约束，相当于删除已有约束
